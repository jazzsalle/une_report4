1. Vercel 환경변수 `DEMO_LOGIN` 삭제 → 재배포 (로그인 화면 안내 사라짐)
2. 계정관리 화면에서 계정별 「비밀번호 초기화」로 개별 비밀번호 발급
3. 이 문서의 공통 비밀번호 줄 삭제
