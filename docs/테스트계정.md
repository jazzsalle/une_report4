- **상황·문서는 모든 계정이 자기가 만든 것만 봅니다**(운영관리자 포함). 다른 계정의 문서는 그 계정으로 들어가서 봅니다.
- **계정 발급과 비밀번호는 운영관리자만** 계정관리 화면에서 직접 입력해 정합니다(자동 생성 없음, 영문·숫자 섞어 8자 이상).
- **API 문서·대응설명서**(`/api-docs`)는 운영관리자·T3Q만, **매뉴얼 분석**(상단 메뉴)은 운영관리자만 열립니다. 로그인하지 않으면 열리지 않습니다.
- 로그인 화면에서 계정을 목록으로 고릅니다 — 운영관리자 · 부산광역시 관리자 · 경상북도 관리자 · T3Q 담당자, 그 밖의 계정은 「직접 입력」.
- 기상특보 지역·재난유형 기본값·연락망은 **로그인한 계정의 기관**을 따릅니다. T3Q 기관은 부산 기준이고, 처음 SOP를 만들 때 예시 연락망이 자동으로 들어갑니다.

## 정식 배포 전 할 일
1. Vercel 환경변수 `DEMO_LOGIN` 삭제 → 재배포 (로그인 화면 계정 목록·안내 사라짐)
2. 계정관리 화면에서 계정별 「비밀번호 지정」으로 개별 비밀번호 발급
3. 이 문서의 공통 비밀번호 줄 삭제
