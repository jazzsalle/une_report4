## 2. 단계 체계와 매핑

매뉴얼에는 서로 맞물리는 세 가지 단계 체계가 있습니다.

| 매뉴얼 대응단계 | 위기경보(p.34의 ★ 표시) | 부산 비상단계(p.22) | 발동 특보 | 회의 주재 | 근무 인원 |
|---|---|---|---|---|---|
| 1단계 징후감지 | 관심·주의 | 상시대비(관심) → 초기대응(주의) | 태풍정보, 호우예비특보, 강풍주의보, 적설예보 | 자연재난과장 | 상황실 3명 → 자연재난과 2명 + 상황실 3명 |
| 2단계 초기대응 | 주의 | 비상1단계(경계) | 태풍예비특보, 호우주의보, 강풍·풍랑경보, 적설 1–3cm | 시민안전실장 | 시민안전실 8명 + 지원부서(호우 12, 태풍 15, 강풍 10, 풍랑 3, 대설 4) |
| 3단계 비상대응 | 경계·심각 | 비상2·3단계(심각) | 호우경보, 태풍주의보·경보, 적설 3cm 이상 | 시장(행정부시장) | 상황관리반 13명 + 협업기능반 26~27명 + 유관기관 + 전직원 1/10~2/10 |
| 4단계 수습·복구 | 경계·심각(특보 해제 후) | 특보 해제 후 | 기상특보 해제 | 시장 | 재대본 해산 전까지 |

**문서 내 불일치 (생성기에서 정해야 할 사항)**
- p.29 위기경보표: 호우경보=경계(중대본 비상2단계), 심각=비상3단계.
- p.22 부산 상황근무 기준과 붙임 6-3-①: 호우주의보 발효 시 '주의→경계' 격상 및 비상1단계 근무.
- 시드 JSON의 `stage`는 p.34 프로세스 표의 ★ 표시를 따랐고, `stages`·`emergencyLevel`·`trigger`를 함께 넣어 다른 기준으로도 다시 매핑할 수 있게 했습니다.
- 수습·복구 카드는 enum을 맞추기 위해 `stage: "심각"`, `phase: "복구"`로 넣었습니다.

## 3. 자연재난과·재대본 단계별 대응 흐름 (핵심 카드)

자연재난과가 주관하는 카드는 54개입니다(공동주관 포함 56개). 아래는 단계별 핵심 흐름입니다.

- **징후감지(p.41–74)**
  - 1-1 기상정보 모니터링(상황실) → 2-1 시장·부시장 1장 보고 → 2-2 다매체 특보전파 → 3-1 (초기)상황판단회의 → 3-2 대응지시 공문/NDMS
  - 3-3·3-4 비상연락체계·근무자 확인 → 3-5 재대본 가동준비 → 3-6 구·군 영상회의·유관기관 협조공문 → 3-7 재해취약지 점검 지시(행정지원 책임관 중복점검, 둔치주차장·지하차도 등급별 통제)
  - 3-8 재난자원 점검 → 3-9 피해조사단(60명) 교육 → 3-10 행안부 보고(매일 05·10·17·22시)
  - 이와 별도로 부서별 카드 3-11~3-21(복지, 통신, 도로, 산림, 건축, 농축산, 수산, 에너지, 교통, 하천)이 있습니다.
- **초기대응(p.76–146)**
  - 4-1 특보 접수 → 5-1 보고 → 5-2 전파 → 5-3 위험예보(댐 방류·산사태) 확인 및 현장출동 → 6-1 상황판단 및 대책회의(시민안전실장)
  - 6-2 대응지시 → 6-3 재대본 운영강화(비상1단계, 재난상황관리반·비상지원반) → 6-4 구·군 재난담당국장 영상회의 → 6-5 재해취약지 중첩점검·사전배수·예경보 시험방송 → 6-6 자원 전진배치 → 6-7 행안부 보고
  - 부서별 카드는 6-8~6-18과 23-1이 있습니다. 주민대피 카드는 40-1(사전대피), 40-5(대피명령), 40-10·40-11(안전취약계층)입니다.
- **비상대응(p.148–193)**
  - 7-1 → 8-1(1보 보고 양식) → 8-2 → 8-3 시장 주재 회의 → 8-4 대응지시(태풍경보 당부 공문) → 8-5 13개 협업기능 실무반 소집 → 8-6 전직원 1/10 비상근무
  - 8-7 구·군 부단체장 영상회의·유관기관 연락관 응소 → 8-8 인명피해우려지역 접근통제·배수펌프장 가동·피해접수·응급조치 → 8-9 유관기관 협력체계 → 8-10 행안부 현장상황관리관 지원 → 8-11 실무반별 책임 구·군 피해파악 → 8-12 보고
  - 협업기관 카드는 11-x(이재민), 15-1, 16-x, 18-1, 24-x, 27-1, 41-x, 44-2입니다.
- **수습·복구(p.195–251)**
  - 9-1 해제 접수 → 9-2 사후점검·피해파악 → 9-3 피해 취합보고 → 9-4 비상근무 해제 → 9-5 피해상황 점검회의(해제 후 3시간 이내) → 9-6 피해복구 대책회의(6시간 이내) → 9-7 구·군 영상회의
  - 14-1 현장방문 → 14-2 복구 유관기관 협력 → 14-3 응급복구비(특교세·재난관리기금) → 14-4 일일상황보고 → 14-5~14-7 당정회의·담화문·인터뷰 → 14-8 재대본 해산 → 14-9 피해조사 재가동
  - 14-10 피해신고 처리(사유시설 10일, 공공시설 7일) → 14-11 피해조사단 → 14-12 중앙합동조사 지원 → 14-13 특별재난지역 건의 → 14-14 복구계획 → 14-15 대처결과 보고(피드백·대체휴무)

각 카드에는 조치목록(임무명), 조치내용, 주관·지원부서, 협업기관, 표준행동 표(세부행동)가 있습니다. 시드에서는 이를 `title`, `content`, `lead`/`leadAll`, `support`, `collab`, `details`로 옮겼습니다. 다음 필드는 카드 본문과 붙임에서 추출했습니다.
- `propagateTo`, `propagateMsg`: 전파 대상과 문안
- `resources`: 장비, 자재, 시스템
- `damageMeasures`: 피해 예방·응급·복구 조치
- `attachments`: 붙임과 서식 쪽

## 5. 상황전파 체계

**접수**
- NDMS(중대본→시 상황실→구·군)
- 방재기상정보시스템
- 기상청 유선 통보
- 기상자문관 메신저

**내부 보고**
- SMS로 시장·부시장에게 통보합니다.
- 1장 보고서는 자연재난과장이 시장에게, 자연재난팀장이 행정부시장에게 보고합니다.

**구·군 지시**
- 주간에는 공문, 야간에는 NDMS·SMS·Fax를 사용합니다.
- 영상회의는 과장급·국장급·부단체장급으로 단계에 따라 격상됩니다.

**대시민 전파**
- 수단: UMS, One-Click(7개 방송사 자막), 문자전광판, BIT, 민방위경보, 전자팩스(아파트 방송), 홈페이지·SNS
- CBS는 행정안전부가 발송합니다.
- 표준문안(UMS): "○월 ○일 ○시 (태풍, 호우) (예비특보, 주의보, 경보)가 발효 됨에 따라, 시설물, 어선·선박 관리 등 안전사고가 없도록 주의 하시기 바랍니다."
- 부록 p.343–346에 재난문자 표준문안 47종(호우·태풍·대설·폭풍해일, 사전대비·대피권고·대피명령·해제·복구)이 있습니다.

**행정안전부 보고**
- 매일 05·10·17·22시에 보고합니다(중대본 발표 1시간 전).
- 인명피해는 소방 확인 후 보고합니다.

**비상연락망(p.25–28)**
- 행안부, 자연재난과, 관련부서 대표번호, 구·군 담당부서 연락처가 있습니다.
- 개인 휴대전화가 들어 있어 시드에는 넣지 않았습니다.
- 유관기관 비상연락망은 이미지 쪽입니다.

## 7. 시드 작성 원칙과 한계

- 카드 114개를 모두 넣었습니다. 단계별로 같은 임무가 반복되는 카드(보고, 전파, 회의)도 별도 액션으로 두었습니다.
- 세부행동은 표준행동 표를 요약·정리한 것이고, 매뉴얼에 없는 내용은 넣지 않았습니다. 다만 `propagateMsg` 일부는 붙임 공문의 요지를 요약했습니다.
- `title`은 PDF 추출 과정에서 띄어쓰기가 사라진 원문 그대로입니다(예: "기상정보모니터링").
- 대설은 카드 본문에 적설·대설이 명시된 경우에만 `hazard`에 넣었습니다. 강풍·풍랑은 세부행동 문구에만 남겼습니다.
- 지하차도 59개소 목록, 인명피해우려지역 365개소, 임시주거시설 494개소 등 대형 현황표는 쪽 참조만 남겼습니다.
- 절차도, 정부 대응체계도(p.12), 유관기관 비상연락망(p.28)은 이미지라 텍스트로 추출되지 않았습니다. 절차도(p.31)는 이미지를 직접 확인했습니다. 흐름은 징후접수 → 전파·보고 → 대응조치 / 사고 시 상황접수 → 상황실 운영 → 현장출동 → 상황판단 → (확대 시) 통지본·지대본 운영 → 수습·복구 → 비상기구 해체 → 모니터링 → 종료입니다.
